# 🥷 Règlement Illégal

Cette partie encadre les activités criminelles, les groupes, les braquages, l'armement et les revendications afin de conserver un équilibre entre risque, progression et qualité RP.

{% hint style="danger" %}
Une activité illégale doit toujours avoir une logique RP. L'objectif n'est pas de multiplier les scènes de violence mais de construire des interactions crédibles.
{% endhint %}
