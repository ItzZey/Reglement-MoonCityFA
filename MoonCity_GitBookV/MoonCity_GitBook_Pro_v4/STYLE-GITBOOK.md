# Finition visuelle GitBook — MoonCity

Ce fichier sert de checklist de personnalisation après synchronisation.

## Accueil

La page `README.md` utilise des blocs `content-ref`. GitBook les affiche comme des grands liens cliquables avec une flèche, ce qui reproduit le fonctionnement des catégories montré dans la référence.

## Bannière d'accueil

Dans GitBook, ouvrir la page **Bienvenue sur MoonCity**, passer en édition, puis ajouter une image juste sous l'introduction. Utiliser une bannière MoonCity au format paysage, idéalement 1920 × 1080 ou un autre ratio 16:9.

## Icônes des pages

Dans la barre latérale GitBook, survoler une page puis choisir **Add icon / Ajouter une icône**. Proposition :

- Bienvenue : 🌙
- Notions de bases : 🙏
- Lexique RP : 📖
- Règles générales : 📜
- Règlement légal : 👨‍⚖️
- Métiers & entreprises : 🏢
- Services publics : 🚓
- Règlement illégal : 🥷
- Réglementation : ⚠️
- Braquages : 💰
- Groupes : 👥
- Armement : 🔫
- Revendications : 📍
- Sanctions & support : 🛡️
- Changelog : 📝

## Thème

Dans **Customize** :

- privilégier un thème sombre ;
- choisir un accent violet / rose pour rappeler l'identité MoonCity ;
- ajouter une favicon ou un logo MoonCity ;
- utiliser la largeur de page **Wide** pour l'accueil ;
- conserver la même identité visuelle sur les pages de catégories.

## Important avec Git Sync

Le contenu Markdown doit être modifié depuis GitHub lorsque Git Sync est activé. Les réglages purement visuels (icônes, thème, favicon, logo, largeur de page) peuvent être faits dans l'interface GitBook.
