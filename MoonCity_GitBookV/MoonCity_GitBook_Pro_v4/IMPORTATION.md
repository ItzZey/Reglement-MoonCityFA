# Importer ce règlement dans GitBook

Ce dossier est conçu pour être utilisé comme base d'un espace GitBook.

## Contenu

- `.gitbook.yaml` : configuration de structure.
- `README.md` : page d'accueil.
- `SUMMARY.md` : navigation générale.
- dossiers thématiques contenant les pages du règlement.

## Méthode conseillée

1. Décompressez l'archive.
2. Placez les fichiers dans un dépôt Git (GitHub, GitLab ou autre solution compatible avec votre flux GitBook) **ou** utilisez l'option d'import Markdown proposée par votre espace GitBook.
3. Conservez les chemins relatifs tels quels afin que les liens internes fonctionnent.
4. Ajoutez ensuite votre logo, votre bannière et vos couleurs directement dans la personnalisation GitBook.
5. Lors d'une modification importante, ajoutez une entrée dans `changelog.md`.

## Personnalisation

Vous pouvez modifier librement :
- les effectifs de groupes ;
- les limites de braquages ;
- les catégories d'armes ;
- les règles de revendication ;
- le nom des services publics ;
- les liens Discord et formulaires MoonCity.
